# YETI-8
YETI-8 is an incomplete fantasy computer slightly inspired by the ZX81.

See the `docs` folder for more information

## Build
#### Emulator
```
cd emu
make
```

Requires SDL2

#### ROM
```
cd rom
make
```

Requires `customasm`

To use the ROM in the emulator, put the `rom.bin` in the `emu` folder
